# ⛏️ Deep Dig

A Cookie Clicker-style idle mining game that runs in your browser. Dig, hire miners, go deeper, and rebuild your empire stronger.

## Play

Visit 

## Features

- Dig by clicking or pressing **Space**
- 22 miners that unlock one at a time, plus tools, 120+ boosts and gem upgrades
- 16 layers, from Topsoil to Beyond
- Core Reset (prestige) for permanent gems
- Golden nuggets, frenzies, Dynamite (**D**) and Overdrive (**O**)
- Quests, 38 trophies, offline earnings and a news ticker
- Autosaves to your browser (localStorage)

## Tech

One self-contained HTML file with vanilla JavaScript and CSS.
